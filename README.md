## 🐛 How to Report a Bug

To help us fix issues as quickly as possible, please follow these rules when opening a new Issue. Poorly formatted or incomplete bug reports may be closed without investigation.

### 1. Search Existing Issues First
Before creating a new issue, use the search bar to check if the bug has already been reported. If it has, add a 👍 reaction to the existing issue instead of creating a duplicate.

### 2. Use the Correct Labels
When creating an issue, apply the appropriate label:
* `bug` - Something isn't working as expected.
* `crash` - The game crashes entirely when using the mod.
* `performance` - FPS drops, memory leaks, or TPS lag related to the clicker.
* `compatibility` - Conflicts with other mods or specific Minecraft versions.
* `ui-ux` - Issues with the configuration menu or HUD.

Please copy and paste the following template into your issue description:

```text

A clear and concise description of what the bug is.
